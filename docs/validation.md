## 功能与代码检查

- Astro/TypeScript 检查：0 错误、0 警告。
- ESLint 与 Prettier 检查通过。
- 单元测试：50 项通过，覆盖发布排除、slug、日期、作者、分类、相册与照片字段、许可继承、照片 ID、EXIF 解析与只填空白的预填规则、CMS 配置，以及模拟的 Pages Functions OAuth/R2 请求。
- 浏览器测试：36 项通过，覆盖真实 Pagefind 搜索、主题 / 语言菜单（含键盘操作）、目录迁移、多作者、封面、瀑布流排布与标签筛选、悬停放大、懒加载、查看器（缩放、滑动、深链接、返回键、焦点恢复）、页头滚动隐藏、页脚写作入口、移动端、无 JavaScript 和明暗主题无障碍。
- 本地 CMS 实际读写：Markdown / MDX 文章，以及相册上传。上传测试嵌入 EXIF 与一段模拟隐私文本，确认表单自动预填、保存的图片为 2400 px WebP，并且不含 EXIF 或该文本。测试开始前会确认代理服务于当前检出，结束后清理文件。
- `pnpm test:variants` 验证了关闭全部模块和后台（包括 `/photos/` 与页脚写作入口）、默认英文、R2 媒体库与关闭 EXIF 预填的配置。该命令会临时修改站点设置并在结束时恢复，不要与手动修改配置同时运行。
- 生产构建输出 51 个页面，Pagefind 索引 12 篇公开示例文章。未发布示例不进入页面、RSS、sitemap 或搜索。
- 端口被占用时可设置 `V7_TEST_PORT`、`DECAP_PROXY_PORT`；构建时的 `DECAP_PROXY_PORT` 同时决定后台连接的代理端口。

## 已知边界

- 没有真实 GitHub OAuth、远程草稿分支、正式发布或 R2 凭据联调；Pages Functions 的权限、上传和失败测试使用模拟服务。R2 上传界面未在浏览器中实际运行过。
- 触屏双指缩放只做了代码层面的实现，自动化测试覆盖了滑动切换，没有在真机上验证捏合手势。
- 自动化浏览器覆盖 Chromium；其他浏览器的兼容回退仍需发布前人工检查。
- Astro/MDX 构建仍给出 `use astro:head-inject` 指令提示，Mermaid 的按需依赖仍有大分块提示；未静默隐藏这些上游提示。MDX、公式、图表渲染和主题重绘测试通过。
- Decap 的依赖树包含旧 peer 版本范围，因此 `pnpm peers check` 仍报告不匹配。本站后台使用 Decap 官方预编译分发资源，与博客 React 页面分开加载；已验证的编辑行为不代表所有第三方编辑器插件都兼容。
- 主题代码和技术文档采用 MIT，文章及编辑内容不纳入代码许可。
